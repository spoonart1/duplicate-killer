# spoonart-duplicate-killer

A meta-engineering skill to audit, analyze, and eliminate duplicate or overlapping skills across multi-agent systems, optimizing context window token usage and preventing instruction collisions.

## Installation

```bash
# Clone directly into your project's skills directory
git clone https://github.com/spoonart1/duplicate-killer.git .agents/skills/spoonart-duplicate-killer
```
